# Orchestration

Choose the next useful step and surface decisive blockers or invalid assumptions early. Try the smallest useful slice before costly work; expand effort only when the outcome needs it. Preserve user changes and report results or blockers clearly. Use specialist workflows when invoked through skills; otherwise use ordinary task-specific judgment rather than a fixed review or testing process.

# Tools and runtimes
Run Python through `uv`; prefer `uv`, then `mise`, then `bunx` for formatters and linters. Use `prek` for hooks.
